Welcome to the **Developer Documentation**! Here you will find guides on Mockrithm's system architecture, API definitions, and integrations.

## Architecture Overview

Mockrithm utilizes a modern Next.js framework combined with Clerk Authentication and Google Firebase.

- **Frontend:** Next.js (App Router), Tailwind CSS.
- **Backend:** Next.js Server Actions and Route Handlers.
- **Auth:** Clerk SDK integration.
- **Database:** Google Cloud Firestore.
- **AI Core:** Google Gemini and Groq API.

---

### Local Environment Setup

1. Clone the repository.
2. Create a `.env` file containing Clerk keys, Firebase credentials, and AI provider tokens.
3. Run `npm run dev` to start the local developer server.
