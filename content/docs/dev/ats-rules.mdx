ATS Specifications

## ATS Schema Rules
          

          
            ATS parsing templates use strict schemas. Ensure data schemas follow the structure below:
          



          ```typescript
interface ResumeData {
  profile: {
    fullName: string;
    email: string;
    phone: string;
    location: string;
    githubUrl?: string;
  };
  experience: Array<{
    role: string;
    company: string;
    location: string;
    startDate: string;
    endDate: string;
    highlights: string[];
  }>;
}
```
